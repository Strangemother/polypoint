# Copyable theatre starters

Each topic below returns one complete JavaScript source block through
`get_knowledge({"topic":"..."})`. The files are bundled with the deck, so
`read_theatre` and repository filesystem access are not needed. Copy the entire
block, including its metadata comment, before making changes.

These starters were selected from the repository's theatre examples. The
bundled versions clean up misleading metadata or duplicate imports in a few
cases, use explicit event offsets for the click example, and handle the
non-perspective branch in the projection example. The scene code otherwise
follows the referenced theatre. Some originals use frame-based animation; see
`animation` before adapting them for consistent speed.

Dependency resolution, JavaScript syntax, and mocked runtime smoke checks are
useful but cannot prove visual correctness or all interaction paths. Validate
the adapted scene in the target browser and inspect the console.
